# Sakura r42 — что исправлено и добавлено

Сборка: `mod-12.10.3-mod-r42`, пакет `com.kami.gram`, arm64-v8a, ключ Telegram.

## 1. Исправлено то, на что были жалобы

### «Текст чёрный, названия чатов не видно» — исправлено в корне
Раньше мод задавал цвета **кодом**: фон карточек делал чёрным
(`windowBackgroundWhite = #000000`), а имя чата тоже чёрным (`chats_name = #000000`).
Получался чёрный текст на чёрном фоне.

Теперь так нельзя by design:

* **P16 переписан полностью.** Берём **родную тёмную тему Telegram**
  (`assets/night.attheme`, 509 ключей, где каждый текст согласован со своим фоном)
  и меняем только цвета — скрипт `mod/kamigram/apply_theme_pro.py`:
  * фон экранов `#000000`, карточки `#1C1C1E`, вложенные `#2C2C2E`, линии `#38383A`;
  * текст: белый `#FFFFFF`, вторичный `#8E8E93`, время в исходящих `#A8C7E8`;
  * облака: входящие `#262628`, исходящие `#2B5278` (как в iOS-теме Telegram);
  * акцент iOS-синий `#0A84FF`, переключатели iOS-зелёный `#34C759`, запись `#FF453A`.
* Тем же набором переписаны `bluebubbles.attheme` (тема дня) и `darkblue.attheme` —
  поэтому **светлая системная тема тоже выглядит тёмно-iOS**, и пропадание текста
  невозможно ни при какой настройке системы.
* Из кода вычищены все переопределения фонов и текста:
  `KamiGramTheme`, `KamiGramConfig`, `IOS_COLORS` в патчах теперь трогают **только
  акценты** (кнопка отправки, галочки, прогресс, ссылки, переключатели).

### «Фиолетовый ужасный» — убран полностью
Во всех палитрах не осталось ни одного `#5E5CE6` (в патчах стоит защита: сборка
падает, если фиолетовый вернётся).

### «Иконка настроек — где шестерёнка» — теперь реально заменена
Причина прошлого провала: патч подставлял **класс, которого нет**
(`org.telegram.ui.Components.kamigram.KamiGramIcons.settings()`), а меню принимает
**идентификатор ресурса**, поэтому официальная иконка и оставалась.

Теперь в сборку кладётся свой вектор `res/drawable/kamigram_ic_ios_settings.xml`
(iOS-шестерёнка, плоская, без стекла) и подставляется как ресурс в:
* меню «три точки» списка чатов;
* настройки бота в чате;
* меню настроек истории;
* веб-экраны Telegram.

### «Почему кэш нельзя чистить — верни» — возвращено
* По умолчанию очистка кэша работает **как в оригинале** (ничего не блокируется).
* Галочка «Скачанное вручную не удалять» (по умолчанию **выключена**) включает защиту:
  автоудаление по сроку и по размеру выключается, а список защищённых файлов
  хранится постоянно (SharedPreferences), а не только в памяти.
* В центре мода — детальный менеджер: размер по категориям (кэш, фото, видео, музыка,
  документы, стикеры, истории, логи), очистка каждой категории отдельно,
  «очистить всё», «освободить память», «забыть защищённые», «отменить все загрузки»,
  переход в родной менеджер загрузок Telegram.

### «Показывать ID не работает» — работает
ID виден в шапке чата рядом со статусом, в меню «три точки» отдельной строкой
(нажатие копирует), в профиле. В центре мода — «мой ID», «@username», ссылка на меня,
всё копируется в буфер.

### «Дизайн прокси — не надо своего» — родной Telegram
Прокси открывается **родным экраном Telegram** (список прокси, дизайн и функционал
как в самом ТГ, белые/серые иконки), плюс быстрые действия мода: вставить ссылку,
проверить все, мгновенно подключиться.

## 2. Что добавлено в этом раунде (код, не картинки)

| Функция | Где |
| --- | --- |
| Единая точка дизайна: тёмная iOS-тема и акценты на **каждом** экране | `ThemeHook` + хук в `ApplicationLoader` (ActivityLifecycleCallbacks) |
| Выбор акцентного цвета: 7 iOS-цветов, применяется сразу | центр мода |
| Фон чата: чёрный (AMOLED) / графит / узор | центр мода |
| Размер текста сообщений: 16 + 0…4 | центр мода → `KamiGramTweaks` |
| Отправка по Enter (значение по умолчанию из мода) | `ChatActivityEnterView` |
| Скрытие текста уведомлений одной галочкой | `KamiGramTweaks` → `EnablePreviewAll/Group/Channel` |
| Запрет скриншотов (FLAG_SECURE) по галочке | `ThemeHook` |
| Счётчик трафика по сессии (↓/↑) | `KamiGramTraffic` (TrafficStats) |
| Счётчик экономии: сколько байт и файлов не скачано | `KamiGramNetFilter` → `KamiGramTraffic` |
| Плоские вкладки без «стекла», компактный режим без подписей | `GlassTabView` |
| Журнал удалённых сообщений (класс готов, экран есть) | `KamiGramDeleted` |

Плюс всё, что было в r40/r41 и осталось: мощный прокси с моментальным переключением,
нулевой трафик стикеров/GIF/историй/премиум-эмодзи/рекламы, призрак (чтение, «печатает»,
«в сети», просмотры историй), ускорение загрузок, без запросов разрешений,
вход по официальному ключу Telegram.

## 3. Технический контроль качества

* Конвейер `mod/apply-mod.sh` проходит целиком (rc=0): P0…P90.
* Все изменённые Java-файлы проверены парсером javalang (37 файлов, ошибок нет,
  единственное исключение — `MessagesController.java`, известное ограничение
  парсера, сборка с ним проходит).
* Тема проверяется на этапе сборки: если в теме появится фиолетовый или пропадёт
  белый текст — сборка падает.
