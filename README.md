# Sakura

Клиент Telegram 12.10.3 с пакетом `com.kami.gram`. Собирается из исходников DrKLO/Telegram скриптом `mod/apply-mod.sh` и workflow `.github/workflows/build-tgmod.yml`. Готовый APK публикуется в GitHub Releases.

## Что включено

- Локальный MTProto-прокси. Ядро собрано из исходника в `mod/proxy-native` (Cloudflare-фронты из этого же исходника). Тумблер «Локальный прокси» в центре Sakura. По умолчанию включён и поднимается до входа в аккаунт. Пока он жив, маршрут его. Если не поднялся или перестал отвечать, включается встроенный SakuProxy.
- SakuProxy — запасной список встроенных прокси. Не подменяет живой локальный маршрут и не трогает прокси, который пользователь добавил сам.
- Стикеры, премиум-эмодзи, истории, GIF, инлайн-боты и остальные медиа грузятся как в оригинальном Telegram. Режима «только текст» нет.
- Поиск в списке чатов: тумблеры людей, групп, ботов и каналов. По умолчанию все включены, выдача как в Telegram.
- Кэш, автоочистка, срок хранения и плеер — как в оригинальном Telegram. Перемотка видео, аудио и музыки штатная.
- Пункт «Поиск Sakura» в меню чата убран. Поиск в чате штатный.

## Сборка

Actions → Build TG Mod APK. Либо локально, после клона DrKLO/Telegram на коммит `9552e5541e1274b9557c9832b204dbfcaf44b3dc`:

```bash
TG_DIR=/path/to/Telegram APP_NAME=Sakura APP_PACKAGE=com.kami.gram \
  ABIS=arm64-v8a bash mod/apply-mod.sh
```

Дальше обычная сборка `TMessagesProj_App:assembleAfatRelease`. Для локального прокси нужен Android NDK: `apply-mod.sh` сам собирает `libsakura_proxy.so`.
