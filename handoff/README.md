# handoff — готовый APK KamiGram + вечный архив версий

Здесь лежат собранные APK и исходники мода, чтобы их можно было скачать **обычной ссылкой**, без похода в Actions.

> **Правило архива: ничего не удаляется.** Каждая сборка сохраняется отдельным файлом навсегда —
> и APK, и запись об исходниках. Старые версии можно скачать и откатиться в любой момент.

## Скачать последнюю сборку (самая простая ссылка)

```
https://github.com/KamiSakyy/Mslosjanznzlalq/raw/arena/01a0bfd6-mslosjanznzlalq/handoff/KamiGram-latest.apk
```

В веб-интерфейсе: открой папку `handoff/` в репозитории → у файла кнопка **Download**.

## Структура

| Путь | Что это |
|---|---|
| `KamiGram-latest.apk` | всегда самая свежая сборка (постоянная ссылка) |
| `apk/KamiGram-<версия>-r<номер>.apk` | каждая сборка отдельно — история версий |
| `apk/KamiGram-latest.apk` | то же, что в корне (удобно, когда смотришь только `apk/`) |
| `sources/MOD_INFO-<версия>-r<номер>.txt` | из какого коммита Telegram собран, какие патчи и с какими настройками |
| `sources/changes-<версия>-r<номер>.patch.gz` | **полный diff** всех правок против исходников Telegram (сжатый) |
| `sources/changes-<версия>-r<номер>.stat.txt` | короткая сводка: какие файлы менялись |
| `sources/SHA256SUMS-<версия>-r<номер>.txt` | контрольные суммы этой версии |
| `SHA256SUMS.txt` | суммы **всех** версий APK, что лежат в архиве |
| `INDEX.md` | таблица всех версий с размерами и суммами |

## Как восстановить исходники любой версии

```bash
# 1. берём исходники Telegram той версии, что указана в MOD_INFO
git clone --recursive https://github.com/DrKLO/Telegram && cd Telegram
git checkout <коммит из MOD_INFO>

# 2. накладываем архивный diff
gunzip -c ../handoff/sources/changes-<версия>-r<номер>.patch.gz | git apply

# 3. либо просто применяем патчер (он идемпотентный и детерминированный)
TG_DIR=$PWD bash mod/apply-mod.sh
```

## Установка

1. Скачай APK на телефон.
2. Разреши установку из неизвестных источников.
3. Поставь. Мод ставится **рядом** с официальным Telegram (свой пакет `com.kami.gram`), вход по номеру как обычно.

## Про подпись

* APK из самых ранних сборок (r8 и раньше) подписаны публичным upstream-ключом Telegram.
* APK, собранные после генерации ключа KamiGram (r11+), подписаны **своим** ключом:
  `mod/keys/kamigram.jks` (alias `kamigram`, пароль `kamigram2026`, RSA 4096, 30 лет).
* Смена ключа = один раз удалить приложение перед установкой новой версии.
  Отпечаток сертификата печатается в логе сборки (`apksigner verify --print-certs`).

## Как сюда попадают файлы

* `.github/workflows/build-tgmod.yml` — при каждой сборке архивирует APK + исходники (`mod/archive-handoff.sh`).
* `.github/workflows/handoff-apk.yml` — быстро кладёт APK из указанной/последней удачной сборки.
* Ручной повтор упаковки: `ARCHIVE_DIR=handoff PUSH=1 bash mod/archive-handoff.sh <apk> <версия> <номер сборки> [MOD_INFO] [patch]`.

Коммиты архива идут с `[skip ci]`, чтобы не запускать новые сборки по кругу.

## Дизайн v2

* **iOS-тёмная тема**: фон чистый чёрный `#000000`, поверхности `#1C1C1E`, входящие сообщения `#262628`,
  исходящие `#2B5278`, разделители `#38383A`, акцент iOS `#0A84FF`, свитчи `#30D158`.
  Градиенты, «стекло» и размытия выключены — плоско и минималистично.
* Плоский фон чата: тяжёлый узор (495 КБ) заменён минимальным SVG.
* Ссылка на прокси (`https://t.me/proxy?server=…`) активирует прокси **сразу**, без ручных шагов.

## Мод: что включено

* Стикеры и премиум-эмодзи **не загружаются вообще** (0 трафика).
* Автоскачивание медиа **выключено по умолчанию** (моб. сеть, Wi-Fi, роуминг).
* MAX ECONOMY: анимации, автоплей GIF/видео, частицы, blur, обои — off.
* Только arm64-v8a, локали ru/en, тяжёлые Lottie-анимации заменены заглушками.
* Проверка обновлений отключена (мод не тянет официальный Telegram).
* Google App Indexing вырезан из кода и зависимостей.
* API-ключи свои не нужны: используются официальные встроенные (`APP_ID=4`).
