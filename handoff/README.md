# handoff — готовый APK KamiGram

Здесь лежит собранный APK мода, чтобы его можно было скачать **обычной ссылкой**, без похода в Actions.

## Скачать последнюю сборку

| Файл | Что это |
|---|---|
| **`KamiGram-latest.apk`** | всегда самая свежая сборка (удобная постоянная ссылка) |
| `KamiGram-<версия>-arm64-v8a.apk` | конкретная версия |
| `SHA256SUMS.txt` | контрольные суммы |
| `MOD_INFO.txt` | из какого коммита Telegram собран, какие патчи применены |

Прямые ссылки (замени ветку, если нужно):

```
https://github.com/KamiSakyy/Mslosjanznzlalq/raw/arena/01a0bfd6-mslosjanznzlalq/handoff/KamiGram-latest.apk
```

Страница папки в веб-интерфейсе: открой `handoff/` в репозитории → у файла кнопка **Download**.

## Установка

1. Скачай APK на телефон.
2. Разреши установку из неизвестных источников.
3. Поставь. Мод ставится **рядом** с официальным Telegram (свой пакет `com.kami.gram`), вход по номеру как обычно.

## Про подпись

* APK, попавшие сюда напрямую из артефактов старых сборок, подписаны публичным upstream-ключом Telegram.
* APK, собранные после генерации ключа KamiGram, подписаны **своим** ключом:
  `mod/keys/kamigram.jks` (alias `kamigram`, пароль `kamigram2026`, RSA 4096, 30 лет).
* Смена ключа = придётся один раз удалить приложение перед установкой новой версии.
  Отпечаток сертификата печатается в логе сборки (`apksigner verify --print-certs`).

## Как сюда попадают файлы

* `.github/workflows/handoff-apk.yml` — кладёт APK из последней удачной сборки (быстро, ~2 минуты).
* `.github/workflows/build-tgmod.yml` — при каждой новой сборке обновляет `handoff/` автоматически.

Обе команды коммитят с `[skip ci]`, чтобы не запускать новые сборки по кругу.

## Мод: что включено

* Стикеры и премиум-эмодзи **не загружаются вообще** (0 трафика).
* Автоскачивание медиа **выключено по умолчанию** (моб. сеть, Wi-Fi, роуминг).
* MAX ECONOMY: анимации, автоплей GIF/видео, частицы, blur, обои — off.
* Только arm64-v8a, локали ru/en, тяжёлые Lottie-анимации заменены заглушками.
* Проверка обновлений отключена (мод не тянет официальный Telegram).
* API-ключи свои не нужны: используются официальные встроенные (`APP_ID=4`).
